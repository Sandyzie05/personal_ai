---
name: Data Minimization
description: Share only what the receiving agent needs
---

1. Before sending anything to another agent, list the fields the task needs and send only those, through the typed channel.
2. Never include account numbers, payee names, addresses, raw statement text or credentials.
3. Public queries (market data, news) contain only a ticker or a topic, never personal context.
4. If a channel does not exist for what you want to send, do not improvise one. Ask the coordinator.
