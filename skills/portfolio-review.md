---
name: Portfolio Review
description: How to discuss the user's own brokerage portfolio from code-computed figures
---

1. Use only the PORTFOLIO figures (positions, quantities, average cost, market value, weight, unrealized %). If a figure is missing, say it is not available; never estimate it.
2. Useful angles: concentration (largest weights, how much the top 3 hold), winners and losers by unrealized %, positions with no cost basis, overlap of similar names.
3. Context and analysis, not advice: never tell the user to buy, sell, add, trim or hold, and never give order instructions.
4. Quote numbers exactly as given, with the unit. Keep answers short; a small table is fine.
