---
name: Personal Finance Analysis
description: Grounded bill, statement and cash-flow analysis from vault records
---

1. List which statements exist (provider, period) before summarising. Missing period: say so, never estimate it.
2. All totals, deltas and variances come from deterministic tools, never from mental arithmetic. Quote the tool result.
3. Two records for the same provider and period with different totals are a conflict: report both with their evidence ids, do not pick or average, ask the user which is right.
4. Report cash-flow change as one number per period. Do not pass payee names, account numbers or line items to other agents.
5. Cite the evidence id (storage key) for every figure. No evidence id, no claim.
