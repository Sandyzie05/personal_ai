Planning Phase Complete

What is Personal AI?

Personal AI is a privacy-first personal assistant framework designed to help you with your most sensitive data — health records, financial information, emails, and personal documents — while maintaining maximum security and privacy.

Core Principle: Your sensitive data never leaves your device. All AI processing happens locally on your machine using open-source models.

This project is currently in the planning phase and ready for implementation. It includes a working proof-of-concept with encrypted data vault, authentication system, and encryption utilities.

Architecture Layers

👤 User Layer

  • Web UI: Streamlit-based chat interface
  • CLI: Command-line interface for automation
  • API: REST API for third-party integrations

🔒 Security Layer

🔐 AES-256-GCM Encryption
🔑 Key Management
✅ Authentication (Password + Biometric)

🤖 AI Processing Layer

  • Ollama: Local LLM hosts (Llama-3.2, Phi-3)
  • Embeddings: Local vector embeddings (nomic-embed-text)
  • RAG: Retrieval-Augmented Generation engine

📊 Data Ingestion Layer

  • File Importer: CSV, PDF, DOCX parser
  • Email Parser: Gmail/IMAP integration
  • Health Data: Apple Health XML parser
  • Financial Data: CSV/Excel import

Security First

AES-256 encryption for all data at rest and in transit. Keys stored in macOS Keychain with fallback to password-based derivation.

Privacy

Local processing only. No data leaves your machine. All AI models run locally on Ollama.

Open Source

Llama-3.2, Phi-3, LlamaIndex, ChromaDB — transparent, auditable, community-driven tools.

Versatile

Data Connectors: Import health data, financial records, emails, and documents with automatic encryption.

User-Friendly

Multiple interfaces: Web UI for everyday use, CLI for automation, and API for integration.

Future-Ready

Extensible architecture: Easy to add new AI models, data connectors, and features.

Technology Stack

AI/ML: Ollama, Llama-3.2, Phi-3, LlamaIndex
Backend: Python (FastAPI/Streamlit)
Encryption: Python cryptography
Database: SQLite + SQLCipher
